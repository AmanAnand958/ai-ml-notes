## 💻 Features Built Into Every Week
* 🧠 **Deep First-Principles Theory**: Detailed mathematical derivations, Mermaid architecture diagrams, and responsive SVG charts.
* 💬 **Hinglish Intuition Callouts**: Conversational Hindi-English mental models breaking down complex ML algorithms.
* 🔮 **Interactive "Predict the Output"**: Real Python prediction puzzles with instant solution reveal.
* 🛠️ **Hands-On Coding Tasks**: Fully structured with input data, assertions, and Colab run buttons.
* 🧪 **Interactive Quizzes**: Multiple-choice assessments with immediate feedback explanations.
* 🃏 **Flip Revision Flashcards**: Spaced repetition cards for retention and interview readiness.
* ⚠️ **Industry Gotchas**: Real production pitfalls (data leakage, memory spikes, gradient vanishing, SettingWithCopyWarning).
* 🎮 **Gamification Engine**: LocalStorage persistence, XP tracking (+150 XP per day), progress bars, and dark/light theme toggle.

## 🛠️ Developer & Build Workflow

The repository is built on a **Single-Source Data Compiler Architecture**:
```
/src
  /data
    week01.yaml ... week26.yaml    # Pure structured content (YAML)
  /template
    week.template.html             # Jinja2 template
pages/weeks/
    week1.html ... week26.html     # Compiled interactive portals
```

### Build & Test Commands:
```bash
# Run Omni-Dimensional Forensic Verification Suite
python3 scripts/omni_audit_master.py
python3 scripts/mega_forensic_deep_scan.py

# Recompile All Weeks (if modifying YAML datasets)
python3 scripts/build.py
```
