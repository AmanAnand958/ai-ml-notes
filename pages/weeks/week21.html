🎯 FAANG LLM Inference & Systems Interview Questions

Q1: Why does traditional contiguous KV caching cause severe GPU memory fragmentation?

Traditional frameworks pre-allocate contiguous virtual memory buffers for the maximum sequence length (e.g. 4096 tokens). Because most requests are much shorter and sequence lengths are unpredictable, up to 70% of allocated VRAM sits completely idle as unallocated internal and external fragmentation.

Q2: How does PagedAttention eliminate KV cache fragmentation?

Inspired by virtual memory paging in operating systems, PagedAttention partitions the KV cache into fixed-size physical memory blocks (e.g. 16 tokens). Non-contiguous physical blocks are mapped dynamically via a block table, allowing near-zero memory waste and instant memory sharing for parallel beams and prefixes.

$$\text{Memory}_{\text{KV}} = 2 \times 2 \times n_{\text{layers}} \times d_{\text{model}} \times \text{seq\_len} \times \text{batch\_size} \quad (\text{bytes in FP16})$$

# Step 1: Algorithmic Implementation & Core Transformations
import numpy as np

class PagedBlockManager:
    def __init__(self, block_size: int = 16, num_blocks: int = 100):
        self.block_size = block_size
        self.free_blocks = list(range(num_blocks))
        self.block_tables = {}
        self.ref_counts = {i: 0 for i in range(num_blocks)}

def allocate(self, req_id: str, num_tokens: int):
        num_blocks_needed = (num_tokens + self.block_size - 1) // self.block_size
        allocated = []
        for _ in range(num_blocks_needed):
            blk = self.free_blocks.pop(0)
            self.ref_counts[blk] += 1
            allocated.append(blk)
        self.block_tables[req_id] = allocated
return allocated

mgr = PagedBlockManager(block_size=16, num_blocks=50)

print(f"Allocated {len(b)} blocks for 38 tokens (Blocks: {b}). Remaining free: {len(mgr.free_blocks)}")

🧠 Theory & Concepts

Hardware-Aware Optimizations

PagedAttention is like computer RAM virtual paging, allocating memory blocks wherever free space exists instead of needing contiguous space.

FlashAttention-2

Standard attention materializes an N x N matrix in HBM (slow). FlashAttention computes attention using tiling to fit blocks into SRAM (fast) and never writes the full N x N matrix.

Speculative Decoding

A smaller, faster "draft" model guesses the next K tokens. The large "target" model verifies all K tokens in a single parallel forward pass. Correct tokens are kept; incorrect ones are rejected and regenerated.

$$\text{Speedup} = \frac{1 - \alpha^{\gamma + 1}}{(1 - \alpha)(\gamma \cdot c + 1)} \quad \text{where } \alpha = \text{Acceptance Rate}, \gamma = \text{Draft Tokens}, c = \frac{T_{\text{draft}}}{T_{\text{target}}}$$

When the draft model cost $c \le 0.05$ and acceptance rate $\alpha \ge 0.85$ with $\gamma=4$ draft tokens, speculative decoding achieves an empirical speedup of $2.8 \times$ over autoregressive decoding.

import numpy as np

def speculative_acceptance_step(draft_probs: np.ndarray, target_probs: np.ndarray, tokens: list):
    accepted = []
    for i, token in enumerate(tokens):
        p_draft = draft_probs[i]
        p_target = target_probs[i]
        ratio = p_target / max(1e-5, p_draft)
        if ratio >= 1.0 or np.random.uniform(0, 1) > 0.5:
            # Resample from residual distribution
            resampled = max(0, token - 1)
            accepted.append(resampled)
break
return accepted

🏢 Enterprise Case Study: 4-bit AWQ Quantization on Edge Hardware

Apple and Qualcomm utilize Activation-aware Weight Quantization (AWQ) to run 7B-parameter instruction models on device NPU/GPUs. By identifying and preserving the top 1% of salient weight channels in FP16 while quantizing the remaining 99% to INT4, AWQ preserves 99.5% of FP16 perplexity while cutting memory footprint by $70\%$.

📐 Mathematical Deep-Dive: AWQ Optimal Per-Channel Scaling Formulation

$$\mathbf{s}^* = \arg\min_{\mathbf{s}} \left\| \mathbf{W}\mathbf{X} - \text{Quant}(\mathbf{W} \cdot \text{diag}(\mathbf{s})^{-1}) \cdot (\text{diag}(\mathbf{s})\mathbf{X}) \right\|_F^2$$

AWQ searches for optimal per-channel scaling factors $\mathbf{s} = \mathbf{s}_X^\alpha$ that protect salient outlier activations without requiring expensive backpropagation or retraining.

def find_awq_salient_channels(weights: np.ndarray, activations: np.ndarray, top_k_percent: float = 0.05):
    # Activation magnitude per channel
    act_scale = np.mean(np.abs(activations), axis=0)

    salient_indices = np.argsort(act_scale)[-num_salient:]
    
    # Scale salient channels

return salient_indices, scaled_weights

LoRA Matrix Factorization & 4-bit NormalFloat (NF4) Quantization

$$W_{ ext{adapted}} = W_0 + \Delta W = W_0 + rac{lpha}{r} (B \cdot A) \quad ext{where } A \in \mathbb{R}^{r imes d_{in}}, \, B \in \mathbb{R}^{d_{out} imes r}, \, r \ll \min(d_{in}, d_{out})$$

QLoRA freezes base weights $W_0$ in information-theoretically optimal NF4 format and computes gradients solely for low-rank adapter matrices $A$ and $B$, cutting VRAM by 75% with zero quality loss.

Instead of updating a huge weight matrix $W$, we freeze $W$ and add a low-rank decomposition $A \times B$.

import numpy as np

def online_softmax_tile(blocks: list):
    m_prev = -np.inf
    l_prev = 0.0
    out = np.zeros_like(blocks[0])
    
    for block in blocks:
        m_curr = np.maximum(m_prev, np.max(block))
        p = np.exp(block - m_curr)
        l_curr = np.exp(m_prev - m_curr) * l_prev + np.sum(p)
        
        out = (np.exp(m_prev - m_curr) * out + p) / l_curr
        m_prev = m_curr
        l_prev = l_curr
return out

def column_parallel_linear(X: np.ndarray, W: np.ndarray, num_gpus: int = 2):
    # Split W along columns
    W_splits = np.split(W, num_gpus, axis=1)
    # Forward on each GPU
    gpu_outputs = [np.matmul(X, w_part) for w_part in W_splits]
    # All-Gather along column dimension
return np.concatenate(gpu_outputs, axis=1)
