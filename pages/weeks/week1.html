1. Why Python? Why Now?

Python is a high-level, interpreted language .

"Interpreted" = runs line by line immediately, no compilation needed.

4. Type Conversion (Casting)

You can convert between types using int() , float() , str() , bool() .

Critical rule: input() always returns a string — you must convert it before doing math.

💡 Why does Python use references? When you write b = a for a list, Python doesn't copy the data — it creates a second name pointing to the same memory location. This is efficient (no wasted RAM for large datasets), but it means modifying b also modifies a . Think of it like two people sharing the same Google Doc: edits by one are visible to the other instantly.
python — type_casting.py 
marks_str = "95"               # This is TEXT, not a number
marks_int = int(marks_str)     # Now it's the number 95
marks_flt = float(marks_str)   # Now it's 95.0

print(marks_int + 5)           # 100  ✅ math works
print(marks_str + "5")         # "955" ⚠️ string concatenation!

# input() always returns str — ALWAYS convert before math
user_age = int(input("Enter age: "))  # convert immediately
birth_year = 2026 - user_age          # now this works ✅

# bool() truthy/falsy rules (important for ML conditionals)
print(bool(0))      # False — zero is always falsy
print(bool(""))     # False — empty string is falsy
print(bool(42))     # True — any non-zero number is truthy
print(bool("hi"))   # True — any non-empty string is truthy

5. f-strings — The Professional Way to Print

f-strings (formatted string literals) provide a clean, readable, and fast way to embed expressions inside string literals using minimal syntax.

python — fstrings.py 
name = "Arjun"
city = "Mumbai"
score = 94.567

# Old way — ugly and error-prone
print("Hello " + name + " from " + city)

# f-string — clean, readable, professional
print(f"Hello {name} from {city}!")

# Format numbers with f-strings
print(f"Score: {score:.2f}")        # 94.57 — 2 decimal places
print(f"Score: {score:.0f}")        # 95 — rounded to int
print(f"Score: {score:10.2f}")      # right-aligned in 10 chars

# You can put expressions inside {}
print(f"Next year age: {21 + 1}")   # 22
print(f"Upper: {name.upper()}")     # ARJUN
💡 Ek line mein: Variable ek labelled box hai RAM mein. int = whole numbers, float = decimals, str = text, bool = True/False. f-string sabse clean printing method hai.

1. Lists — Ordered, Mutable Collections

Lists are the most versatile built-in sequence type in Python, allowing you to store an ordered collection of items that can be dynamically modified.

python — lists.py 
# Create lists with square brackets
ipl_teams = ["MI", "CSK", "RCB", "KKR"]
scores = [89, 76, 94, 61]

# Indexing: 0 = first, -1 = last
print(ipl_teams[0])      # "MI"
print(ipl_teams[-1])     # "KKR"
print(ipl_teams[1:3])    # ["CSK", "RCB"] — stop index NOT included!

# Modifying lists
ipl_teams.append("SRH")        # add to end
ipl_teams.insert(1, "PBKS")    # insert at index 1
ipl_teams.remove("RCB")        # remove first occurrence of value
last = ipl_teams.pop()          # remove & return last item
ipl_teams.sort()                # sort alphabetically IN-PLACE (changes original)
copy_sorted = sorted(ipl_teams) # sort and return NEW list (original unchanged)

# Useful operations
print(len(ipl_teams))    # count of items
print("MI" in ipl_teams) # True — membership check
print(scores.index(94)) # 2 — position of value 94

# List comprehension — most important Python pattern for ML
passed = [s for s in scores if s >= 75]   # [89, 76, 94] filter
doubled = [s * 2 for s in scores]         # transform every item
In ML, your entire training dataset is a list of lists (or NumPy array, which IS a list underneath). list comprehensions are used to filter data, normalize values, and transform labels — you'll write dozens of these in Pandas and scikit-learn.

3. Sets — Unique Values, Fast Membership

Sets are unordered collections of unique elements, highly optimized for $O(1)$ fast membership testing and mathematical operations.

python — sets.py 
# Sets store only UNIQUE values — auto-removes duplicates
students_a = {"Raj", "Priya", "Amit", "Raj"}
print(students_a)   # {"Raj", "Priya", "Amit"} — no duplicate Raj

# Remove duplicates from a list (classic trick)
marks = [85, 92, 85, 78, 92]
unique = list(set(marks))   # [85, 92, 78]

# Set operations — very useful in data analysis
python_devs = {"Raj", "Priya", "Amit"}
ml_devs = {"Priya", "Sara", "Amit"}

print(python_devs | ml_devs)   # union — all unique names
print(python_devs & ml_devs)   # intersection — know BOTH Python + ML
print(python_devs - ml_devs)   # difference — Python only, not ML

# Membership check is O(1) — instant even for 1 million items
print("Priya" in python_devs)  # True

4. Dictionaries — The Most Important Structure in ML

grades = {"Raj": 88, "Priya": 92, "Amit": 75}
passed = {name: g for name, g in grades.items() if g >= 80}

5. The collections Module (Advanced Data Structures)

In ML (especially NLP and graphs), built-in dictionaries and lists are sometimes too basic.

Python's collections module provides specialized, high-performance data structures.
python — collections_demo.py 
from collections import Counter, defaultdict, deque

# 1. Counter: Automatically counts frequencies (great for NLP token counts)
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
word_counts = Counter(words)
print(word_counts)  # Counter({'apple': 3, 'banana': 2, 'orange': 1})

# 2. defaultdict: A dict that doesn't throw KeyError if key is missing
graph = defaultdict(list)
graph['node1'].append('node2')  # 'node1' automatically created as empty list first!

# 3. deque: Double-ended queue. Super fast O(1) appends/pops from BOTH ends
# Standard lists are O(n) for popping from the front.
queue = deque([1, 2, 3])
queue.appendleft(0)  # Fast insertion at the beginning

    if len(y_true) != len(y_pred):
        raise ValueError("y_true and y_pred must have equal lengths")

    else:
        raise ValueError(f"Unsupported loss: {loss_type}")
    
    total = sum(calc(yt, yp) for yt, yp in zip(y_true, y_pred))

# Day 5: Robust File I/O + Exception Handling
import csv
import os

class DataParseError(Exception):
    """Raised when a row cannot be parsed."""
    pass

def parse_row(row: list, row_num: int) -> dict:
    """Validate and parse a CSV row."""
    if len(row) < 3:
        raise DataParseError(f"Row {row_num}: expected 3+ cols, got {len(row)}")
    try:
        return {
            'name': row[0].strip(),
            'score': float(row[1]),
            'grade': row[2].strip().upper()
        }
    except ValueError as e:
        raise DataParseError(f"Row {row_num}: {e}") from e

def process_csv(input_path: str, output_path: str, error_log_path: str) -> dict:
    """Process CSV, skip bad rows, write clean output, log errors."""
    valid_rows, error_rows = [], []

    with open(input_path, 'r', encoding='utf-8') as fin:
        reader = csv.reader(fin)
        for row_num, row in enumerate(reader, start=1):
            try:
                parsed = parse_row(row, row_num)
                valid_rows.append(parsed)
            except DataParseError as e:
                error_rows.append(str(e))

    # Write valid output
    with open(output_path, 'w', encoding='utf-8', newline='') as fout:
        writer = csv.DictWriter(fout, fieldnames=['name', 'score', 'grade'])
        writer.writeheader()
        writer.writerows(valid_rows)

    # Write error log
    with open(error_log_path, 'w', encoding='utf-8') as ferr:
        ferr.write('\n'.join(error_rows))

    return {'valid': len(valid_rows), 'errors': len(error_rows)}

# Day 6 Task 2: Dataset Preprocessor Hierarchy — OOP Inheritance
from abc import ABC, abstractmethod
from typing import List, Dict, Any
import numpy as np

class BasePreprocessor(ABC):
    """Abstract base class for data preprocessors."""
    def __init__(self, name: str):
        self.name = name
        self.is_fitted = False

    @abstractmethod
    def fit(self, data: Any) -> 'BasePreprocessor':
        pass

    @abstractmethod
    def transform(self, data: Any) -> Any:
        pass

    def fit_transform(self, data: Any) -> Any:
        return self.fit(data).transform(data)

class TabularPreprocessor(BasePreprocessor):
    """Standardizes numeric tabular features."""
    def __init__(self):
        super().__init__("TabularPreprocessor")
        self.means: np.ndarray = None
        self.stds: np.ndarray = None

    def fit(self, data: np.ndarray) -> 'TabularPreprocessor':
        self.means = np.mean(data, axis=0)
        self.stds = np.std(data, axis=0) + 1e-8
        self.is_fitted = True
        return self

    def transform(self, data: np.ndarray) -> np.ndarray:
        if not self.is_fitted:
            raise RuntimeError("Preprocessor must be fitted before transform")
        return (data - self.means) / self.stds

class TextPreprocessor(BasePreprocessor):
    """Cleans and tokenizes raw text streams."""
    def __init__(self, lowercase: bool = True):
        super().__init__("TextPreprocessor")
        self.lowercase = lowercase
        self.vocab: Dict[str, int] = {}

    def fit(self, data: List[str]) -> 'TextPreprocessor':
        unique_tokens = set()
        for text in data:
            tokens = text.lower().split() if self.lowercase else text.split()
            unique_tokens.update(tokens)
        self.vocab = {tok: idx for idx, tok in enumerate(sorted(unique_tokens))}
        self.is_fitted = True
        return self

    def transform(self, data: List[str]) -> List[List[int]]:
        if not self.is_fitted:
            raise RuntimeError("Preprocessor must be fitted before transform")
        result = []
        for text in data:
            tokens = text.lower().split() if self.lowercase else text.split()
            result.append([self.vocab.get(tok, -1) for tok in tokens])
        return result

# Day 7: NumPy-only Neural Network Forward Pass
import numpy as np

def relu(x: np.ndarray) -> np.ndarray:
    return np.maximum(0, x)

def softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable softmax."""
    x_shifted = x - x.max(axis=1, keepdims=True)
    exp_x = np.exp(x_shifted)
    return exp_x / exp_x.sum(axis=1, keepdims=True)

def cross_entropy_loss(probs: np.ndarray, labels: np.ndarray) -> float:
    """Cross-entropy loss. labels is integer class indices."""
    n = len(labels)
    correct_probs = probs[np.arange(n), labels]
    return -np.mean(np.log(correct_probs + 1e-9))

def linear(x: np.ndarray, W: np.ndarray, b: np.ndarray) -> np.ndarray:
    return x @ W + b

# Architecture: 4 input → 8 hidden (ReLU) → 3 output (softmax)
np.random.seed(42)
BATCH, IN, HIDDEN, OUT = 16, 4, 8, 3

W1 = np.random.randn(IN, HIDDEN) * 0.01
b1 = np.zeros(HIDDEN)
W2 = np.random.randn(HIDDEN, OUT) * 0.01
b2 = np.zeros(OUT)

X = np.random.randn(BATCH, IN)
y = np.random.randint(0, OUT, size=BATCH)

# Forward pass
h = relu(linear(X, W1, b1))       # (16, 8)
out = softmax(linear(h, W2, b2))  # (16, 3)
loss = cross_entropy_loss(out, y)
