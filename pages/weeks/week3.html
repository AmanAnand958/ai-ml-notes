import pandas as pd

url = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"

def missing_report(data):
    missing_count = data.isnull().sum()
    missing_pct = (missing_count / len(data) * 100).round(2)
    report = pd.DataFrame({"Missing": missing_count, "Percent": missing_pct})
    report = report[report["Missing"] > 0].sort_values("Percent", ascending=False)
    print("Column          Missing  Percent  Flag               Rec")
    print("=" * 60)
    for col in report.index:
        pct = report.loc[col, "Percent"]
        flag = "DROP CANDIDATE" if pct > 50 else ""
        dtype = data[col].dtype
        if dtype in ["int64", "float64"] and pct <= 50:
            rec = "median" if abs(data[col].skew()) > 1 else "mean"

            rec = "most_frequent"
        else:
            rec = "-"

# Compare Imputation Strategies
import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer
from sklearn.metrics import mean_squared_error
url = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"
df = pd.read_csv(url)
np.random.seed(42)
true_ages = df["Age"].dropna().values
mask = np.random.rand(len(true_ages)) < 0.2
corrupted = true_ages.copy()
corrupted[mask] = np.nan
rmse_mean = np.sqrt(mean_squared_error(true_ages[~mask], [np.nanmean(corrupted)]*sum(~mask)))
rmse_median = np.sqrt(mean_squared_error(true_ages[~mask], [np.nanmedian(corrupted)]*sum(~mask)))
knn = KNNImputer(n_neighbors=5)
knn_imputed = knn.fit_transform(corrupted.reshape(-1,1)).ravel()
rmse_knn = np.sqrt(mean_squared_error(true_ages[~mask], knn_imputed[~mask]))
print(f"RMSE Mean:   {rmse_mean:.3f}")
print(f"RMSE Median: {rmse_median:.3f}")
print(f"RMSE KNN:    {rmse_knn:.3f}")
best = "KNN" if rmse_knn<min(rmse_mean,rmse_median) else ("Mean" if rmse_mean<rmse_median else "Median")
print(f"Best: {best}")
assert best is not None, "best should not be None"

Box plots outliers dikhate hain visually — IQR se 1.5x zyada door jo points hain wo outliers hain. Inhe handle karna — winsorize ya remove — important decision hai.

Think of it like this: Cricket batting positions (Opener=1, Middle=2, Finisher=3) ka encoding theek hai kyunki order matter karta hai. Lekin agar cities ko encode karein (Delhi=1, Mumbai=2, Chennai=3), model sochega Mumbai aur Delhi ke beech ka average Chennai hai! Yeh bilkul galat hai — cities ke beech koi order nahi hota.
Tree-based models (Decision Tree, Random Forest, XGBoost) can handle Label Encoding on nominals because they split on values rather than assuming order.

But linear models (Linear Regression, Logistic Regression, SVM) absolutely require proper One-Hot Encoding for nominal features — they assume numeric order matters.

Feature engineering ka matlab hai: raw features se naye aur better features banana. Jaise age aur year_of_birth se age_group banana — model ko ye zyada useful lagta hai!

KNN algorithm aur SVM distances calculate karte hain features ke beech. Models that compute distances (KNN, SVM, K-Means) or use gradient descent (Linear Regression, Neural Networks, Logistic Regression) are heavily affected by feature scale.

Tree-based models (Decision Tree, Random Forest, XGBoost) are completely unaffected — they split on values, not distances.

Always scale for the former group; skip for the latter.

import pandas as pd

from sklearn.model_selection import cross_val_score

basic = pd.get_dummies(df[basic_f], drop_first=True)
basic_acc = cross_val_score(RandomForestClassifier(n_estimators=50,random_state=42), basic, y, cv=5).mean()
df["FamilySize"] = df["SibSp"]+df["Parch"]+1
df["IsAlone"] = (df["FamilySize"]==1).astype(int)
df["Title"] = df["Name"].str.extract(r", (\w+)\.")
eng_f = basic_f + ["FamilySize","IsAlone","Title"]
eng = pd.get_dummies(df[eng_f], drop_first=True)
eng_acc = cross_val_score(RandomForestClassifier(n_estimators=50,random_state=42), eng, y, cv=5).mean()
print(f"Basic features accuracy: {basic_acc:.4f}")
print(f"With engineered features: {eng_acc:.4f}")
print(f"Improvement: {(eng_acc-basic_acc)*100:.2f}%")

✅ Key Takeaways

📢 Ek line mein: Production mein Full Preprocessing + Visualization Pipeline ko use karte waqt edge cases aur mathematical constraints ko pehle validate karo, taaki downstream deployment bilkul rock-solid rahe!
  • Missing Data: MCAR/MAR/MNAR types. Drop if >70% missing. Fit imputer on train, transform test. KNNImputer > mean for correlated data.
  • Encoding: Nominal → One-Hot (drop_first=True). Ordinal → custom map. High cardinality → Target Encoding. Trees = Label OK; Linear = One-Hot required.
  • Scaling: Distance-based/gradient models need it; trees don't. Outliers → RobustScaler. Normal data → StandardScaler. Bounded → MinMaxScaler.
  • Matplotlib: fig, ax = plt.subplots(). ax-level API for multi-plot. Always tight_layout() + savefig() for reports.
  • Seaborn: histplot (dist), boxplot/violinplot (spread), heatmap (correlation), pairplot (all relationships). hue= splits by category.
  • Feature Engineering: New features from domain knowledge. Bin continuous, combine columns, extract datetime parts. Always on train only.
