> 🔍 Unsupervised Learning: K-Means, Silhouette Score & DBSCAN Density Clustering

Unlike Supervised Learning, Unsupervised Learning discovers hidden patterns in unlabelled data $X$:

  • K-Means Clustering: Minimizes Within-Cluster Sum of Squares (WCSS inertia) by iteratively updating $K$ cluster centroids.
  • Silhouette Score $s(i)$: Measures cluster separation vs cohesion (range $-1$ to $+1$).
  • DBSCAN: Density-based spatial clustering that groups dense regions and detects noise/outliers without pre-specifying $K$.

> 🎮 Reinforcement Learning Foundations: Q-Learning & Bellman Equation

In Reinforcement Learning (RL) , an Agent interacts with an Environment to maximize cumulative reward:

  • Bellman Optimality Equation: $Q^*(s,a) = \mathbb{E}[R_{t+1} + \gamma \max_{a'} Q^*(S_{t+1}, a') | S_t=s, A_t=a]$.
  • Q-Learning Update Rule: $Q(s,a) \leftarrow Q(s,a) + \alpha [r + \gamma \max_{a'} Q(s',a') - Q(s,a)]$.
  • Deep Q-Networks (DQN): Approximates $Q(s,a)$ using a Deep Neural Network with Experience Replay.

🧠 Theory & Concepts

1. Mean Absolute Error (MAE) vs Mean Squared Error (MSE)

MAE calculates the average magnitude of absolute errors. MSE squares the errors before averaging them. Because of the squaring operation, MSE penalizes large errors disproportionately more than small errors.

$$\text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$ L1 Loss. Robust to outliers, but gradient is constant (not smooth at zero). $$\text{MSE} = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2$$ L2 Loss. Penalizes larger errors heavily, smooth gradient, easy to differentiate. $$\text{RMSE} = \sqrt{\text{MSE}}$$ Root Mean Squared Error. Converts units back to original y scale.

2. Coefficient of Determination (R² Score)

R² compares your model's predictions to a baseline model that always predicts the mean of target variables (ŷ = mean(y)). It represents the proportion of variance in the dependent variable that is predictable from the independent variables.

$$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}}$$ Where $SS_{\text{res}} = \sum(y_i - \hat{y}_i)^2$ [sum of squared residuals], and $SS_{\text{tot}} = \sum(y_i - \bar{y})^2$ [total sum of squares]

# Solution for Task: NumPy Regression Metrics Suite
import numpy as np

def compute_regression_metrics(y_true: np.ndarray, y_pred: np.ndarray) -> dict:
    errors = y_true - y_pred
    mse = np.mean(errors ** 2)
    rmse = np.sqrt(mse)
    mae = np.mean(np.abs(errors))
    
    ss_res = np.sum(errors ** 2)
    ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
    r2 = 1 - (ss_res / (ss_tot + 1e-10))
    
    return {"MSE": round(mse, 4), "RMSE": round(rmse, 4), "MAE": round(mae, 4), "R2": round(r2, 4)}

🧠 Theory & Concepts

1. The Confusion Matrix

Confusion Matrix is a tabular representation of the model's classification performance, comparing actual values with predicted values.

graph TD subgraph "Actual Positive" P_TP["Predicted Positive: TP"] P_FN["Predicted Negative: FN"] end subgraph "Actual Negative" P_FP["Predicted Positive: FP"] P_TN["Predicted Negative: TN"] end
TP: True Positive, TN: True Negative, FP: False Positive, FN: False Negative.

2. Precision vs Recall Trade-off

Precision: Out of all predicted positives, how many are actually positive? You care about minimizing False Positives.

Recall (Sensitivity): Out of all actual positives, how many did we successfully find? You care about minimizing False Negatives.

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$ What fraction of predictions were correct? $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$ What fraction of positive cases did we capture? $$\text{F1-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$ Harmonic mean. Penalizes extreme values of either precision or recall.

3. ROC Curve and AUC

The Receiver Operating Characteristic (ROC) curve plots True Positive Rate (Recall) vs False Positive Rate (FP / (FP + TN)) at various decision thresholds. AUC ranges from 0 to 1; a model with AUC = 0.5 is no better than random guessing.

import numpy as np

def compute_classification_metrics(y_true: np.ndarray, y_pred: np.ndarray) -> dict:
    tp = np.sum((y_true == 1) & (y_pred == 1))
    tn = np.sum((y_true == 0) & (y_pred == 0))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))

    accuracy = (tp + tn) / len(y_true)
    
    return {"Accuracy": round(accuracy, 4), "Precision": round(precision, 4), "Recall": round(recall, 4), "F1": round(f1, 4)}

🧠 Theory & Concepts

1. Bias-Variance Decomposition

The total expected prediction error of any ML model can be decomposed into three mathematically separate parts:

$$\text{Total Error} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$$ Bias: Error from erroneous assumptions (e.g., fitting a line to circular data). High bias → Underfitting. Variance: Sensitivity to small fluctuations in training set. High variance → Overfitting. Irreducible Error (noise): Noise in data generation. Cannot be reduced regardless of algorithm.

2. Visualizing the Tradeoff

graph TD Low["Low Complexity Underfitting / High Bias"] --> Opt["Optimal Fit Low Generalization Error"] Opt --> High["High Complexity Overfitting / High Variance"]
As model complexity increases, training error drops, but validation error curves back up.

3. Diagnostics: What to Do

Condition Behavior Primary Fixes
High Bias (Underfitting) Both train and validation error are high. Minimal gap. Increase complexity, add features, reduce regularization.
High Variance (Overfitting) Low training error, high validation error. Large gap. Add more data, apply L1/L2 regularization, reduce features, prune trees.

🧠 Theory & Concepts

1. Parameters vs Hyperparameters

Parameters: Internal variables learned by the model during training (e.g. weights $w$ and bias $b$ in regression, node splits in Decision Trees).

Hyperparameters: External configurations specified by the developer before training starts (e.g. learning rate, number of neighbors $k$ in KNN, max depth of a Decision Tree).

2. Cross-Validation (K-Fold vs Stratified K-Fold)

Simple train/test split has high variance depending on where the split occurred. K-Fold splits the dataset into $K$ blocks, training on $K-1$ and validating on the remaining block, repeating $K$ times. Stratified K-Fold ensures each fold maintains the same percentage of target class labels as the complete dataset.

4-Fold Cross Validation. We average validation scores across all 4 iterations.

3. GridSearchCV vs RandomizedSearchCV

  • GridSearchCV: Exhaustively searches all possible combinations in a given search space. Slow but guaranteed to find the best configuration in the grid.
  • RandomizedSearchCV: Samples a fixed number of combinations randomly from statistical distributions. Much faster and highly recommended when search space is large.

4. Scikit-learn Pipelines

Pipelines prevent data leakage by ensuring that all transformations (like scaling, imputing) are fitted ONLY on the training folds during cross-validation, and never on validation folds.

1. K-Nearest Neighbors (KNN) Classifier

KNN classifies a new data point based on the majority vote of its $k$ closest neighbors in the feature space. It is a lazy learner (no training phase; it stores the dataset in memory and does all calculations during prediction).

$$\text{Euclidean Distance} = \sqrt{ \sum_{i=1}^n (x_i - y_i)^2 }$$ Straight-line distance. Sensitive to variable scales (requires normalization!). $$\text{Manhattan Distance} = \sum_{i=1}^n |x_i - y_i|$$ Grid-like taxi cab distance. Useful in high dimensional spaces.

2. Naive Bayes Classifier

Naive Bayes uses probability formulas derived from Bayes' Theorem to classify instances. It calculates the conditional probability of each class given the input features, choosing the class with highest probability.

$$P(C | X) = \frac{P(X | C) \times P(C)}{P(X)}$$ Where C is class, X is features vector [x₁, x₂, ..., xₙ].

Why is it called "Naive" ? Because it assumes all input features are independent of each other given the class label. Even though this is almost never true in real life, the classifier performs surprisingly well on text classification (spam detection, sentiment analysis).

    'education': np.random.choice(['HS','College','Graduate'], n),
    'region':    np.random.choice(['North','South','East','West'], n),
