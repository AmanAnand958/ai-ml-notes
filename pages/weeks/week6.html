🧠 Theory & Concepts

1. The Full Linear Regression Story

$$ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ = Xβ$$ Matrix form: X is (n×p) design matrix (with 1s column for intercept), β is (p×1) weight vector $$Loss (MSE) = (1/n) Σ(yᵢ − ŷᵢ)² = (1/n)||y − Xβ||²$$ We minimize this. Set derivative to zero → closed-form OLS solution: $$β* = (XᵀX)⁻¹ Xᵀy$$ The Normal Equation. Direct, exact, no iteration needed — but expensive for large n.

import numpy as np
import pandas as pd
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# Load California Housing dataset (classic regression benchmark)
data = fetch_california_housing()
X_df = pd.DataFrame(data.data, columns=data.feature_names)
y    = data.target   # median house value in $100k

# Use just 2 features for visualization clarity
X_raw = X_df[['MedInc', 'AveRooms']].values

X_train, X_test, y_train, y_test = train_test_split(
    X_raw, y, test_size=0.2, random_state=42)

# Scale features — critical before OLS with multiple features
sc = StandardScaler()
X_tr = sc.fit_transform(X_train)
X_te = sc.transform(X_test)

# ── OLS from scratch using Normal Equation ──────────────────
# Add bias column (column of 1s)
X_tr_b = np.column_stack([np.ones(len(X_tr)), X_tr])   # (n, 3)
X_te_b = np.column_stack([np.ones(len(X_te)), X_te])

# β* = (XᵀX)⁻¹ Xᵀy
beta = np.linalg.inv(X_tr_b.T @ X_tr_b) @ X_tr_b.T @ y_train

print("OLS Coefficients (scratch):")
print(f"  Intercept : {beta[0]:.4f}")
print(f"  MedInc    : {beta[1]:.4f}")
print(f"  AveRooms  : {beta[2]:.4f}")

# Predictions and MSE
y_pred_scratch = X_te_b @ beta
mse_scratch = np.mean((y_test - y_pred_scratch)**2)
print(f"\nTest MSE (scratch OLS): {mse_scratch:.4f}")

from sklearn.linear_model import LinearRegression

    # WANT: points on the diagonal line. Curves mean non-normal residuals.

    axes[1,0].scatter(y_pred, np.sqrt(np.abs(residuals)), alpha=0.4,

    # 4. Residual distribution histogram
    axes[1,1].hist(residuals, bins=40, color='#b47cfc', alpha=0.8, edgecolor='black')

import pandas as pd
import numpy as np
from sklearn.datasets import fetch_california_housing
from sklearn.linear_model import LinearRegression

# Variance Inflation Factor (VIF) — quantifies multicollinearity
# VIF = 1: no multicollinearity
# VIF 1-5: moderate (acceptable)
# VIF > 10: HIGH — problematic, remove this feature

def calc_vif(X_df):
    vif_data = {}
    for col in X_df.columns:
        # Regress col on all other columns → R²
        others = X_df.drop(columns=[col])
        model  = LinearRegression().fit(others, X_df[col])
        r2     = model.score(others, X_df[col])
        vif_data[col] = 1 / (1 - r2) if r2 < 1 else float('inf')
    return pd.Series(vif_data, name='VIF').sort_values(ascending=False)

data = fetch_california_housing()
X_df = pd.DataFrame(data.data, columns=data.feature_names)
vif = calc_vif(X_df)
print(vif)
print(f"\nFeatures with VIF > 5 (potential multicollinearity):")
print(vif[vif > 5])

# Complete solution for: Linear Regression from Scratch — Both Methods

import numpy as np
import matplotlib.pyplot as plt

class LinearRegressionScratch:
    """Linear Regression using Normal Equation: w = (X^T X)^(-1) X^T y"""
    def __init__(self):
        self.weights = None
        self.bias = None
    
    def fit(self, X, y):
        X = np.array(X, dtype=np.float64)
        y = np.array(y, dtype=np.float64)
        
        # Add bias column
        X_b = np.c_[np.ones(X.shape[0]), X]
        
        # Normal equation
        self.theta = np.linalg.pinv(X_b.T @ X_b) @ X_b.T @ y
        self.bias = self.theta[0]
        self.weights = self.theta[1:]
        return self
    
    def predict(self, X):
        X = np.array(X, dtype=np.float64)
        return X @ self.weights + self.bias
    
    def r2_score(self, X, y):
        y_pred = self.predict(X)
        ss_res = np.sum((y - y_pred) ** 2)
        ss_tot = np.sum((y - y.mean()) ** 2)
        return 1 - (ss_res / ss_tot)

Lasso vs Ridge Regression?
Lasso (L1): Adds absolute weight penalty, leads to sparse feature selection. Ridge (L2): Adds squared weight penalty, shrinks weights.
Core concept: What is the significance of R-squared? in Linear Regression — Deep Dive?
Proportion of variance in the dependent variable explained by features: 1 - (SS_res / SS_tot).
Mean Squared Error (MSE)?
Average of squared differences between true and predicted values. Highly sensitive to outliers.
Core concept: What is the significance of MAE vs MSE? in Linear Regression — Deep Dive?
MAE (Mean Absolute Error) uses absolute differences (linear penalty); MSE uses squared differences (quadratic penalty for outliers).
Multicollinearity?
When two or more predictor variables are highly correlated, inflating the variance of regression coefficients.
⚠️ Gotcha: Gradient Descent Vanishing & Explosions

Unnormalized input features lead to oscillating gradients and slow convergence. Always normalize features before gradient descent.

Linear regression assumes a straight line. The real world is curved. Polynomial regression bends that line — but bend too much and the model memorises noise. Aaj hum ML ka sabse important concept seekhenge: Bias-Variance Tradeoff.

2. Bias-Variance Tradeoff — The Central Tension of ML

$$Expected Test Error = Bias² + Variance + Irreducible Noise$$ Three separate sources of error. Only bias and variance are controllable. $Bias: error from wrong assumptions (e.g., fitting a line to a curve)$ $Variance: sensitivity to small fluctuations in training data$
MODEL STATE TRAIN ERROR TEST ERROR BIAS VARIANCE FIX
Underfitting High High High Low More features, higher degree, more complex model
Just Right Low Low Moderate Moderate Keep this!
Overfitting Very Low High Low High Regularization, reduce degree, more training data

1. Why Regularise? The Shrinkage Intuition

$$OLS Loss = Σ(yᵢ − ŷᵢ)²$$ $$Ridge Loss = Σ(yᵢ − ŷᵢ)² + α × Σβⱼ² [L2 penalty — squared coefficients]$$ $$Lasso Loss = Σ(yᵢ − ŷᵢ)² + α × Σ|βⱼ| [L1 penalty — absolute coefficients]$$ α (alpha) = regularization strength. α=0 → pure OLS. α→∞ → all coefficients → 0.

# Day 40 Task 2: Ridge from Scratch via Closed-Form Normal Equation
import numpy as np

def ridge_closed_form(X: np.ndarray, y: np.ndarray, alpha: float) -> np.ndarray:
    """Computes w = (X^T X + alpha * I)^(-1) X^T y"""
    n_samples, n_features = X.shape
    X_bias = np.c_[np.ones((n_samples, 1)), X]
    I = np.eye(n_features + 1)
    I[0, 0] = 0  # Do not regularize intercept
    w = np.linalg.inv(X_bias.T @ X_bias + alpha * I) @ X_bias.T @ y
    return w

np.random.seed(42)
X = np.random.randn(100, 5)
y = X @ np.array([1.5, -2.0, 0.0, 3.0, 0.5]) + 2.0 + np.random.randn(100) * 0.1

2. R² — The Most Misunderstood Metric

$$R² = 1 − SS_res / SS_tot$$ SS_res = Σ(yᵢ − ŷᵢ)² (residual sum of squares — model error) SS_tot = Σ(yᵢ − ȳ)² (total sum of squares — variance in data) $$R² = 0: model no better than predicting the mean$$ $$R^2 < 0 \text{: model WORSE than predicting the mean! (always possible with wrong model)}$$$ $$R² = 1: perfect predictions$$
METRIC FORMULA UNIT OUTLIER SENSITIVITY BEST FOR
MSE Σ(y−ŷ)²/n y² (confusing!) Very High (squares errors) When large errors are very costly (structural engineering)
RMSE √MSE Same as y High Same as MSE but interpretable — most common
MAE Σ|y−ŷ|/n Same as y Low (robust) When outliers exist and large errors aren't catastrophic
MAPE Σ|y−ŷ|/(y)/n × 100% % Medium (fails if y≈0) Business reporting, demand forecasting (% error is intuitive)
R² 1 − SS_res/SS_tot Unitless [−∞, 1] High Comparing models on same dataset. NOT across datasets.
Adjusted R² 1 − (1−R²)(n−1)/(n−p−1) Unitless High Feature selection — penalises adding irrelevant features
Huber Loss MSE if |e|≤δ, else MAE Same as y² Low (controlled) When outliers exist but you still want MSE's differentiability
python — huber_loss.py 
import numpy as np
from sklearn.linear_model import HuberRegressor

# Huber Loss — combines MSE (smooth) and MAE (outlier-robust)
# δ (delta) is the threshold:
# |error| ≤ δ → use MSE (quadratic, differentiable, fast gradient)
# |error| > δ → use MAE (linear, doesn't explode for huge errors)

def huber_loss(y_true, y_pred, delta=1.35):
    errors = y_true - y_pred
    is_small = np.abs(errors) <= delta
    huber = np.where(is_small,
                     0.5 * errors**2,
                     delta * (np.abs(errors) - 0.5 * delta))
    return np.mean(huber)

y_true = np.array([10, 20, 30, 40, 500])  # 500 is an outlier
y_pred = np.array([12, 19, 31, 42, 100])

mse_loss   = np.mean((y_true - y_pred)**2)
mae_loss   = np.mean(np.abs(y_true - y_pred))
huber_val  = huber_loss(y_true, y_pred, delta=10)

print(f"MSE loss   : {mse_loss:.1f}  ← dominated by the 500 outlier")
print(f"MAE loss   : {mae_loss:.1f}  ← balanced")
print(f"Huber loss : {huber_val:.1f}  ← in between")

def compute_classification_metrics(y_true, y_pred_probs, threshold=0.5):
    y_pred = (y_pred_probs >= threshold).astype(int)
    tp = np.sum((y_true == 1) & (y_pred == 1))

SOLUTION & EXPLANATION
The Bug: If you one-hot encode all categories, the columns become perfectly collinear because their sum is always a vector of ones (which matches the intercept column). This multicollinearity destabilizes linear regressions. You must drop one category to serve as the baseline.

X = pd.get_dummies(df['color'], drop_first=True)
model = LinearRegression().fit(X, df['price'])
